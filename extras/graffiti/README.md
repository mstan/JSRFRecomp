# Bundled graffiti artwork

These are the two supplied emblems. No player's imported artwork or saved
games are included. Installing either image adds a new design; it never
replaces an existing one.

Open **Mods > Manage Graffiti > Import image** and choose one of these PNGs:

| Image | Size | Detail | Fit |
| --- | --- | --- | --- |
| RPTK-SS.png | SS / 1:1 | 4x | Fit |
| RAID-Discord-XL.png | XL / 4:1 | 4x | Fit |

The PNGs retain their source detail: RPTK is 512 x 512, RAID is 1736 x 398.
The game's native design remains compatible with the original editor. Its
HD companion displays the extra detail without changing the painted wall area.

Sources, supplied by the project owner:

- RPTK mascot: https://retroportingtoolkit.com/site-icon.png
  (https://retroportingtoolkit.com/)
- RAID Discord emblem: https://github.com/mstan/nesrecomp/raw/master/.github/raid-discord.png

Artwork remains the property of its respective creator. These files are not
original Jet Set Radio Future game assets.
