# Third-party attribution

Shared implementations and their exact notices are recorded in the
[pinned xboxllr inventory](xboxllr/THIRD_PARTY_ATTRIBUTION.md). The gitlink and
[framework.json](framework.json) identify the matching framework revision.
Component licenses remain in effect independently of this repository's
owner-original license.

That inventory includes the xboxrecomp family, native runtime and renderer,
audio/DSP components, launcher dependencies and behavioral references. A root
repository license does not override a component's file-level provenance.
The framework's [license scope](xboxllr/LICENSE-SCOPE.md) excludes the current
GPL-dependent private pilot from the intended shipping product.

The separately developed JuMatt JSRF recompile was reviewed as described in the
[pinned reference assessment](docs/REFERENCE-JSRF-UNLEASHED.md). That assessment
imported no implementation body or game data. Title-owned code here supplies
configuration, reviewed revision facts, mods and build/validation glue; it does
not include original CPU function bodies or media. The curated gameplay image
has a separate [documentation notice](docs/screenshots/NOTICE.md).

See [Credits](CREDITS.md) for prominent contributor recognition and the local
[license scope](LICENSE-SCOPE.md) for distribution status.
