# Documentation images

`gameplay-21x9.png` is an unchanged 1260×540 native Linux gameplay capture
from the November 1, 2026 AppImage qualification. It shows a real 21:9 view.

`custom-graffiti-controller.jpg` and `custom-graffiti-raid.jpg` are frames from
the owner's November 2, 2026 gameplay recording, `2026-11-02 15-21-43.mp4`,
at 165.0 seconds and 186.0 seconds respectively.
They show locally imported artwork used during gameplay. The original
3440×1388 adaptive-ultrawide frame is preserved without cropping or stretching;
these two wider captures are not labeled as exact 21:9 frames. JPEG encoding
is the only image conversion. The source recording and personal game data are
not distributed in this repository.

`chuo-widescreen.png` is an unchanged screenshot from the October 21, 2026
development preview's original-save loading and movement check in Chuo Street.
It shows actual rendered gameplay, including the optional visual configuration.

applicable rights holders. The framework's source-code license does not
relicense the depicted game assets. The image illustrates this development
preview; it is not a redistributable game-data package.
