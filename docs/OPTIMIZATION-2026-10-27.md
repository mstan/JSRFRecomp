# Native optimization qualification

The framework pin retains prepared native draw reuse, immutable shader stream
plans, validated vertex-owner index hints and the renderer-independent display
wait correction. Both supported title definitions request capability-checked
MSVC x64 Release IPO. Unsupported hosts and development profiles retain normal
compilation; original game timing and selectable graphics features remain.

Matched native-save Garage workloads are **neutral/inconclusive**, rather than
proven performance wins. USA reference CPU costs are16.681/16.777/16.473/16.058ms
per source swap versus14.845/16.526 for the candidate. Original-revision
references are15.556/15.954 versus15.677/14.828. Initial reference A/A drift is
0.57%; later paired effects vary with background load. No reproducible individual
game regression is accepted in exchange for Blinx's measured improvement.
Near60 source swaps/s in this Garage is not a simulation-rate or scanout claim.

Both revisions load the current native save through original menus into actual
Garage gameplay. USA additionally loads Shibuya10014 and returns to Garage10000
through an explicitly assisted handover, with original loading, screenshots and
normal movement. Prerequisites are bypassed; organic exits and story completion
are not established by that smoke. Final pinned binaries are checked separately
before the owner handoff. Existing NAS-only fixture/setup limitations remain
separate from introduced regressions.
