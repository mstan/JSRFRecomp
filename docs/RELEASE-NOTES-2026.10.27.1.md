# Windows preview - 2026.10.27.1

Both supported NTSC-U revisions receive the qualified native preparation and
whole-program Release compilation package, including the unconditional shared
display-only vblank wait correction. The launcher selects the matching native
executable by the original game hash.

Matched native-save Garage samples for both revisions are neutral/inconclusive:
no proven performance win and no reproducible per-game regression. Measured
source swaps are not simulation updates or display frames. Other games' gains
are not used to offset a JSRF regression.

Adaptive widescreen, sharp original-frame defaults, graphics options, native
graffiti tools/emblems, Early Test Runs and existing optional presentation mods
are retained. Both revisions pass native-save loading into gameplay. The USA
build also passes assisted Shibuya loading/movement and Garage return; that
bypasses prerequisites and does not claim organic story completion. The owner
accepted the final game visually and audibly. Shared baseline fixture failures
remain separately recorded, rather than counted as passing checks.

Keep your complete existing `data` folder, external saves/HDD profile, personal
graffiti and imported-disc caches when updating. Only the authored RPTK and
RAID Discord source emblems are bundled; private progress/console identity and
review profiles are excluded. Other game revisions remain unsupported.
