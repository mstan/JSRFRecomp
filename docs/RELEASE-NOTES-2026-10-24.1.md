# Windows preview 2026.10.24.1

The USA standalone retail Jet Set Radio Future executable (certificate revision
1) is now supported alongside the existing NTSC-U revision 4. Selecting either
recognized XBE automatically launches its matching precompiled native program.
Keep the complete extracted game asset folder beside default.xbe. Direct ISO
import remains unavailable; original game files are supplied separately.

Each revision has separate default console identity and save storage. Updating
an existing installation preserves revision-4 progress when its existing data
folder and any selected external save storage are retained. Keep those files
when extracting the update. Do not replace them with another player's profile.

The shared Windows controller fix, adaptive widescreen, image-quality mods,
camera inversion and Early Test Runs remain included. Both optimized native
executables build and pass their visual and original-menu comparison checks.
The standalone input was checked through New Game, movement, four window
aspects, actual graffiti input, native saving and a fresh-process Load Game.
The original revision still loads its existing checkpoint. Matched short
Garage samples sustain 60 presentations per second for each revision.

These checks admit another original revision with representative gameplay,
save and mod coverage. They do not qualify the entire campaign or all extra
modes. See [revision evidence and limits](REVISION-USA-STANDALONE.md).

Matching project/framework source and prepared dependency source accompany
the Windows download, including inside source/. Original media, console dumps,
signing inputs and player saves are excluded. Source changes remain on their
review branches pending the owner's merge approval.
